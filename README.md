# 油耗保養紀錄

https://z88487561.github.io/vehicle-log/

記錄汽機車的加油、保養與各項費用，自動計算平均油耗、每日費用、每公里費用與每年花費。可管理多台車，也能匯入現有的 Excel／CSV 紀錄。資料只存在本機瀏覽器，不會上傳。

## 功能

- 多台車輛管理，每台車可以設定起算日（購車日）和起始里程。
- 加油紀錄：日期、金額、總里程、公升（或用油價換算）、是否加滿、備註。輸入時會即時算出油價和這次的油耗。
- 掃描電子發票：在加油表單按「掃描發票」（或加油頁的「掃發票」），對準發票左側 QR，自動帶入日期、金額（發票總計）和公升（油品品項的數量），然後把焦點移到里程欄。發票有多個品項時只取油品的公升；發票內沒有油量時只帶入日期和金額。每張發票的號碼會記下來，重複掃描會提醒。需要 HTTPS 才能使用相機，影像只在本機處理。
- 所有數值（金額、里程、公升、油耗、油價、每日／每公里費用、百分比）都顯示到小數點第二位；筆數、天數、加油次數這類計數維持整數。
- 保養／費用紀錄：日期、項目、分類、金額、里程。分類會依項目文字自動判斷（機油→保養、險→保險、燃料費→稅費…）。
- 總覽：平均油耗（最近 5 次、上次）、每日費用、總花費、每公里費用、每年估算、行駛里程、平均油價、距上次換機油的里程與天數、花費分類比例、年度統計。可以切換費用是否包含購車價。
- 匯入 .xlsx／.csv：自動找出有「日期」「金額」的表頭；有「公升／本次加油」欄的列當作加油，其他列當作費用。「總花費」這類彙總表預設不匯入，相同的紀錄會自動略過。
- 完整 CSV：把所有車輛、加油、費用放在同一個 CSV（第一欄「類型」為 車輛／加油／費用）。可以直接「分享」給其他裝置（手機會叫出系統分享選單，不支援的瀏覽器改為下載），也能用 Excel 開啟編輯。「匯入完整 CSV」會**覆蓋**目前所有資料，匯入前會顯示目前與匯入後的筆數，並列出被略過的列。Excel 另存的 Big5 CSV、`2026/1/5` 日期、`1,200` 千分位都能讀。同名車輛匯出時會自動加上 (2)。
- 匯出完整備份（.json）、從備份還原、匯出單一車輛的 CSV（可用 Excel 開啟）。
- 可安裝為 PWA，離線可用。

## 計算方式

| 項目 | 算法 |
| --- | --- |
| 本次油耗 | 滿到滿：上次加滿到這次加滿之間的里程 ÷ 期間加的油量（第一筆只當起點；「未加滿」的油量會併入下一次加滿） |
| 平均油耗 | 所有滿到滿區間的里程總和 ÷ 油量總和 |
| 每日費用 | 總花費 ÷（起算日到最後一筆紀錄的天數 + 1） |
| 每公里費用 | 總花費 ÷（目前里程 − 起始里程） |
| 每年估算 | 每日費用 × 365，使用滿半年後才顯示 |

## 專案檔案

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 頁面骨架 |
| `styles.css` | 樣式（跟隨系統深色／淺色） |
| `core.js` | xlsx／csv 讀取、匯入對應、統計計算（不依賴 DOM） |
| `scan.js` | 相機掃描發票 QR（BarcodeDetector + jsQR） |
| `jsQR.js` | QR 解碼函式庫（複製自 einvoice-scanner） |
| `app.js` | 介面、表單、匯入、備份 |
| `manifest.webmanifest`、`sw.js` | PWA 設定與離線快取 |
| `icon.svg`、`icons/` | 圖示 |

除了 jsQR 之外沒有外部相依套件。資料存在 `localStorage` 的 `vehicle-log:v1`。

更新程式後，記得把 `sw.js` 裡的 `vehicle-log-v3` 版本號加一，否則已安裝的裝置會一直使用舊的快取。
